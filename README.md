# traffic-light-controller-modern-counter
Traffic Light Controller + Modern Counter Design

Overview

A digital logic project demonstrating a traffic light controller using sequential circuits and counter design.

Features

Three traffic light states: Red, Yellow and Green.

Clock-based state transitions.

Counter-based timing mechanism.

Sequential logic implementation.

Working Principle

The system uses a clock signal and counter to control the duration of each traffic light. Once the counter reaches its predefined value, the controller changes to the next state.
